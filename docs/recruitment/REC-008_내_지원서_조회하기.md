# 내 지원서 조회하기

| 항목 | 내용 |
|------|------|
| ID | REC-008 |
| HTTP Method | GET |
| Domain | Recruitment |
| 화면 | User |
| 상태 | 완료 |
| 우선순위 | P1 |
| Notion URL | - |

---

## 📝 개요

로그인한 사용자가 특정 모집 공고에 대한 자신의 임시저장(DRAFT) 지원서를 조회한다.
지원서가 `SUBMITTED` 상태인 경우 제출 완료로 간주하여 열람을 허용하지 않으며 403을 반환한다.
지원서가 없는 경우 404를 반환한다.

---

## 📐 비즈니스 규칙

- [ ] 로그인한 사용자만 조회할 수 있다.
- [ ] `(recruitment_id, user_id)` 조합으로 지원서를 조회한다.
- [ ] `DRAFT` 상태의 지원서만 조회 가능하다.
- [ ] `SUBMITTED` 상태의 지원서는 열람 불가로 403을 반환한다.
- [ ] 해당 모집 공고에 지원서가 없으면 404를 반환한다.
- [ ] 자신의 지원서만 조회할 수 있다. (다른 사용자의 지원서 조회 불가)
- [ ] `DRAFT` 상태이므로 일부 필드가 null일 수 있다.

---

## ⚠️ 예외 처리

| 상황 | HTTP 상태 | 에러 코드 | 사용자 메시지 |
|------|-----------|-----------|--------------|
| AccessToken 미포함 | 401 | `TOKEN_NOT_FOUND` | 토큰이 존재하지 않습니다. |
| AccessToken 형식 오류 또는 위변조 | 401 | `INVALID_TOKEN` | 유효하지 않은 토큰입니다. |
| AccessToken 만료 | 401 | `EXPIRED_TOKEN` | 만료된 토큰입니다. |
| `recruitmentId` 경로 변수에 숫자가 아닌 값 입력 | 400 | `INVALID_PARAMETER_TYPE` | 파라미터 'recruitmentId'의 값이 올바르지 않습니다. |
| 존재하지 않는 모집 공고 | 404 | `RECRUITMENT_NOT_FOUND` | 해당 모집 공고를 찾을 수 없습니다. |
| 지원서가 존재하지 않는 경우 | 404 | `APPLICATION_NOT_FOUND` | 지원서를 찾을 수 없습니다. |
| 이미 제출된 지원서인 경우 | 403 | `APPLICATION_ALREADY_SUBMITTED` | 제출된 지원서에 접근할 수 없습니다. |
| 데이터베이스/서버 내부 오류 | 500 | `INTERNAL_SERVER_ERROR` | 서버 내부 오류가 발생했습니다. |

## 🔌 API 스펙

> 협의 상태: ⚪ 미협의

**Request**

```
GET /api/v1/recruitment/{recruitmentId}/applications/me
```

| 파라미터 | 위치 | 타입 | 필수 | 설명 |
|---------|------|------|------|------|
| Authorization | Header | STRING | ✅ | `Bearer {userAccessToken}` |
| recruitmentId | Path | LONG | ✅ | 조회할 모집 공고 ID |

**Request 예시**

```
GET /api/v1/recruitment/12/applications/me
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

```json
{

    "applicant_id": 42,
    "status": "DRAFT",
    "track": "ENGINEERING",
    "name": "홍길동",
    "email": "hong@example.com",
    "phone": null,
    "university": null,
    "major": null,
    "minor_double_major": null,
    "last_semester": null,
    "military_status": null,
    "birth_date": null,
    "graduation_date": null,
    "grad_school_plan": null,
    "answers": [
      {
        "question_id": 1,
        "answer": "저는 데이터 엔지니어링에 관심이 많아..."
      },
      {
        "question_id": 19,
        "answer": {
          "9월 7일(일)": ["12:00~14:00", "16:00~18:00"],
          "9월 8일(월)": []
        }

    ],
    "created_at": "2026-08-10T10:00:00",
    "updated_at": "2026-08-10T13:00:00"
  }

```

**Response (404 Not Found — 지원서 없음)**

```json
{
  "status": 404,
  "error_code": "APPLICATION_NOT_FOUND",
  "message": "지원서를 찾을 수 없습니다."
}
```

**Response (403 Forbidden — 이미 제출된 지원서)**

```json
{
  "status": 403,
  "error_code": "APPLICATION_ALREADY_SUBMITTED",
  "message": "제출된 지원서에 접근할 수 없습니다."
}
```

**협의 포인트**

- [ ] `answers` 응답에 `question_id`만 포함할지, 질문 내용(`content`)까지 포함할지

|------|---------------|-----------|-----------|
| 2026-05-16 | 지원서 없을 때 `404` vs `null` 반환 | `404` | 프론트에서 지원서 미존재 상태를 명확히 구분할 수 있도록 에러 코드로 처리. |
| 2026-05-19 | SUBMITTED 상태 조회 허용 vs 금지 | 금지 (403 반환) | 제출 후 지원서 내용을 다시 열람하지 못하도록 하는 서비스 정책. 프론트는 403 응답으로 제출 완료 화면을 표시. |

## 📎 비고

- User 전용 API로, 요청 헤더에 유효한 User AccessToken(`Authorization: Bearer {token}`)이 포함되어야 한다.
- `DRAFT` 상태의 지원서는 일부 필드가 null일 수 있다. 프론트에서 null 처리 필요.
- `APPLICATION_NOT_FOUND`, `APPLICATION_ALREADY_SUBMITTED`는 신규 추가 ErrorCode다.
- 프론트 응답 분기: 404 → 빈 폼 표시, 200 → 기존 DRAFT 데이터 로드, 403 → 제출 완료 화면 표시.
