## 📝 개요

리크루팅 페이지 상단에 노출할 모집 마감 기한 정보를 조회한다.
프론트엔드는 이 API에서 반환된 마감 시각을 기준으로 현재 시각과의 차이를 계산하여 사용자에게 실시간 카운트다운 UI를 제공한다.

---

## 💾 데이터 구조 (ERD)

---

## 📐 비즈니스 규칙

- [ ] 현재 모집 중인 공고의 마감 일시를 반환한다.
- [ ] 마감 일시는 ISO 8601 형식(`yyyy-MM-dd'T'HH:mm:ss`)으로 제공하여 타임존 혼선을 방지한다.
- [ ] 모집 기간이 이미 종료된 공고는 노출하지 않는다. ⇒ 에러 반환

---

## ⚠️ 예외 처리

| 상황 | HTTP 상태 | 에러 코드 | 사용자 메시지 |
|------|-----------|-----------|--------------|
| 마감 일시 조회 시 활성 공고 없음 | 404 | `RECRUITMENT_NOT_FOUND` | 해당 모집 공고를 찾을 수 없습니다. |
| 서버 내부 오류 | 500 | `INTERNAL_SERVER_ERROR` | 서버 내부 오류가 발생했습니다. |
