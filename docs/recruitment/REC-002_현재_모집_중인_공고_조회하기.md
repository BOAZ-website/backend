|------|------|
| ID | REC-002 |
| HTTP Method | GET |
| Domain | Recruitment |
| 화면 | 리크루팅 |
| 상태 | 완료 |
| 우선순위 | P0 |
| Notion URL | https://www.notion.so/36359289864881df9267e96ca22ee9d6 |

---

## 📝 개요

리크루팅 페이지에서 특정 기수의 상세 모집 정보(일정, 설명, 홍보 링크 등)를 조회한다.
`recruitment` 테이블 데이터를 기반으로 지원자에게 공고 내용과 홍보 책자 링크를 제공하여 지원 결정을 돕는다.

---

## 💾 데이터 구조 (ERD)

---

## 📐 비즈니스 규칙

- [ ] 모집 기간 내 공고는 조회 가능하며 응답에 `is_active: true`로 표시한다.
- [ ] 모집 기간이 지난(마감된) 공고도 조회 가능하나 `is_active: false`('모집 마감')로 표시한다.
- [ ] `is_active`는 저장 컬럼이 아니라 모집 기간(`start_date`~`end_date`)으로 서버가 계산하는 파생값이다. (Recruitment 엔티티에 is_active 컬럼 없음)
- [ ] 모집 기수(`term`) 값은 유니크해야 하며, 동일 기수에 대한 공고는 1개만 존재한다.
- [ ] `brochure_url`이 존재하는 경우에만 홍보책자 링크를 제공한다.

## ⚠️ 예외 처리

| 상황 | HTTP 상태 | 에러 코드 | 사용자 메시지 |
|------|-----------|-----------|--------------|
| `term` 경로 변수에 숫자가 아닌 값 입력 시 | 400 | `INVALID_PARAMETER_TYPE` | 파라미터 'term'의 값이 올바르지 않습니다. |
| 필수 파라미터 누락 | 400 | `MISSING_PARAMETER` | 요청 파라미터가 누락되었습니다. |
| 존재하지 않는 기수(`term`) 조회 | 404 | `RECRUITMENT_NOT_FOUND` | 해당 모집 공고를 찾을 수 없습니다. |
| 데이터베이스/서버 내부 오류 | 500 | `SERVER_ERROR` | 서버 내부 오류가 발생했습니다. 잠시 후 다시 시도해주세요. |

## 🔌 API 스펙

> 협의 상태: ✅ 확정

**Request**

```
GET /api/v1/recruitment/{term}
```

| 파라미터 | 위치 | 타입 | 필수 | 설명 |
|---------|------|------|------|------|
| term | Path | INT | ✅ | 조회할 모집 기수 값 |

**Request 예시**

```
GET /api/v1/recruitment/27
```

**Response (200 OK)**

```json
{
  "status": 200,
  "data": {
    "recruitment_id": 12,
    "term": 27,
    "start_date": "2026-02-20T00:00:00+09:00",
    "end_date": "2026-03-05T23:59:59+09:00",
    "schedule": [
      {"step": "서류 모집", "start": "2025-12-08", "end": "2025-12-22", "sequence": 1},
      {"step": "서류 발표", "start": "2025-12-30", "end": "2025-12-30", "sequence": 2},
      {"step": "면접", "start": "2026-01-03", "end": "2026-01-04", "sequence": 3},
      {"step": "최종 발표", "start": "2026-01-10", "end": "2026-01-10", "sequence": 4}
    ],
    "is_active": true,
    "brochure_url": "https://example.com/boaz25_brochure.pdf"
  }
}
```

**Response (404 Not Found)**

```json
{
  "status": 404,
  "error_code": "RECRUITMENT_NOT_FOUND",
  "message": "해당 모집 공고를 찾을 수 없습니다."
}
```

**협의 포인트**

- [x] 비활성화된 경우 모집 공고는 보이게 하되 모집 마감 상태로 표시할지, 또는 공고 조차 안보이게 할 것인지
- [x] `start_date`와 `end_date` 반환 형식 ⇒ KST(UTC+09:00) 기준
